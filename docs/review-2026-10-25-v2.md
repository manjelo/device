# Code review: RadioSim v2 (2026-10-25)

Scope: `src/` (radio, components, hooks, styles, assets), `e2e/`, `playwright.config.ts`, `vitest.config.ts`, `vite.config.ts`. Contract docs: `docs/architecture.md` (v2), `docs/accuracy-matrix.md`, `src/assets/radio/controls.md`, and the prior review `docs/review-2026-10-25-initial-build.md`.
Method: read-only. No builds, tests, lint, or Playwright runs. No owner build or test result for this revision was supplied.

## Summary

The v2 changes close all four prior Major findings in code: the SVG root is a labelled group, the view buttons keep native Enter, CLR and ENT are 46 units tall, and the duplicate accuracy table is gone. The architecture boundary holds: `src/radio` has no React or DOM imports, and accuracy text comes only from `CONTROL_ACCURACY` and `CONTROL_LABEL`. The LCD strings, menu copy, startup frame and sound behaviour are labelled and off by default. The new review finds one regression: after a click on a view, theme or sound button, all radio keyboard shortcuts silently stop working (M1). Build, lint and test results for this revision were not reported, so approval is conditional on M2. Verdict: Ready with fixes.

## Verdict: Ready with fixes
